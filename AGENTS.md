# NameThatBaby contributor guide

Keep the app fully local: no runtime HTTP, analytics, ads, accounts, or remote config. Keep domain logic in `lib/core` pure and test it before changing UI. Run `/tmp/flutter/bin/dart format .`, `/tmp/flutter/bin/flutter analyze`, `/tmp/flutter/bin/flutter test`, and `python3 tools/name_data/validate_database.py assets/data/names.sqlite assets/data/manifest.json` before handoff. Never commit `tools/name_data/raw_cache`, credentials, QR contents, session keys, or user data. Data adapters cache raw inputs locally and must preserve source metadata. QR protocol changes require a version increment and backwards-compatibility note. Mutable-storage schema changes require a migration. Update goldens intentionally with the documented Flutter command.
